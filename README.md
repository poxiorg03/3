# EasyMinePlots 1.1.0

Paper/Purpur 1.21.11, Java 21.

Zmiany: działka 16×16 liczona od postawionego bloku (-8..+7), TAB, PPM w blok otwiera GUI, ItemDisplay modelu 3D nad blokiem lodestone.

## Instalacja
Wgraj repozytorium z zachowaniem katalogów, uruchom GitHub Actions. Podmień JAR na serwerze przy wyłączonym serwerze. Włącz osobno paczkę zasobów ZIP w kliencie.

UWAGA: wykonaj kopię plugins/EasyMinePlots/dzialki.yml i świata. W istniejących działkach zmienią się granice, ponieważ są teraz liczone od bloku, nie chunka. Testuj na kopii.

Model 3D jest nakładką ItemDisplay na magnetycie, więc widoczność modelu zależy od paczki zasobów klienta. Nie jest to pełna podmiana fizycznego bloku.
